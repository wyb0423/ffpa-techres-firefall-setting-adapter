# CMF 接入验证

## 核对范围

本地 Community Mod Framework 1.65.0，元数据支持 Victoria 3 1.13.*。预期加载顺序为 CMF → Tech & Res → Firefall → 本适配包；现有可选共享法律覆盖仍应置于适配包之前。

逐项核对了组织分组注册、contextless 创建、共用侧栏、日志挂载点、成员名单组件、进度组件与信件／电报继承链。预期依赖栈中，相关 CMF GUI 与宏文件没有被 Tech & Res 或 Firefall 同路径覆盖；另搜索了两个依赖 GUI 中相应类型定义，未发现替代定义。新 GUI 引用的图像资源均在预期栈中存在。没有修改 Workshop。

## 可运行检查

```sh
python3 scripts/check_compact.py --workshop-root "$WORKSHOP_ROOT"
python3 scripts/check_compact_votes.py
python3 scripts/check_aid_pool_scripts.py
python3 scripts/check_aid_pool_model.py
python3 scripts/check_journal_presentation.py
python3 scripts/check_cmf.py --cmf-root "$CMF_ROOT"
git diff --check
```

`WORKSHOP_ROOT` 指实际 `workshop/content/529340`；`CMF_ROOT` 指其 `3385002128` 目录。不将开发机器路径写入运行脚本。

新增检查解释真实 CMF 注册包装和本 Mod 的初始化条件，验证未成立、成立、重复调用以及已有其他组织注册；用实际只读 script values 验证 0–24 个投票国下所有有效赞成／反对组合，检查门槛与既有三项通过条件等价；覆盖三个原任务及五类援助阶段的时间边界。还检查 GUI 挂载点、类型接口、contextless 分组、只读公共页、双语电报颜色及 GUI 括号／命名。GUI 的静态归一化解析不等于引擎 GUI 解析。

保留原机制检查，包括三个月投票、九个月休会、晚入会、任务上限、重试期限、会员成长、援助收费与供给、年度调整和上游指纹。原本的“只有两个日志”断言改为两个国家日志加一个公共组织日志，没有增加每国履约日志。

## 第二批明细与操作分组

- 公共页增加四类投票名单和提案标记；非表决期恢复普通会员列表。五类援助使用同一个展示模板，并分别读取本类的提供／接受标记。执行期显示已结算供给；报名期单独标为预计供给，实际收费与收入固定显示零。
- 国家总览的21个原按钮分成议会11个、长期协议4个、工程与援助6个。每个按钮恰好归入一组，继续使用原生 `scripted_journal_entry_button`，保留其显隐、可用条件、工具提示与执行对象。过滤依据 CMF 旧局势 GUI 中 `ScriptedButton.GetName` 对本地化键的比较先例；未接入旧局势对象模型。
- 双向跳转通过 JE 引用，GUI 检查成员身份（本国入口）、引用存在及目标日志有效／活动。新实例 immediate 绑定，旧实例在初始化或月脉冲补接；移除国别引用不影响会员成长或计时变量。
- 新检查覆盖名单分类互斥、晚入会／资格丢失、五类援助报名期残留金额屏蔽、缺失修正时零收支、供给比例、21按钮完整分组、跳转保护及旧日志引用补接／退会清理。

第二批核对时修正了第一批进度数值及检查器的 `min/max` 语义错误：Paradox 的 `min` 是下界，`max` 是上界。原版 `command_values.txt` 使用 `max` 限制战斗宽度，本仓库援助检查器也以 `min` 保证非负。进度现以 `min = 0 / max = 1` 限幅，投票所需赞成票以 `min` 取更高下界；补充独立断言防止检查器与实现再次同时写反。原表决结算与援助收费未使用这些展示值。

## 待实机验收

本机保存的 `content_load.json` 启用了 CMF，但不包含 Tech & Res、Firefall 与本适配包，因此它不是本次目标加载栈；未启动游戏或改动启动器配置。本次只提供静态和局部状态证据。

- 新游戏成立协定后出现一个组织入口；旧档首次加载或下个月补建一次，连续读档不重复。
- 会员、非会员、退会重入及零／一个会员时，公共页与名单正确；协调国更换／灭国不残留。
- 国家切换后显示该国立场和任务；所有原按钮仍按原权限执行，AI 全流程继续运行。
- 四类投票名单显示国家名与提案国，空分组无国家；援助提供／报名或接受名单与实际执行一致。
- 三个操作分页全部按钮可达且无重复；悬停能看到原条件与费用，点击执行一次。旧档进入后不残留另一套原按钮区。
- 公共页／国家页双向跳转、切换国家、退会与重入正常；无有效本国日志时不允许跳转。检查中文及英文分页标签、国家长名和成员较多时滚动。
- 表决中的进度条随投票变化，满条不提前结算；保持全局三个月／九个月规则。
- 准备达标／失败、工程完成／中止、援助报名转执行／退出后显示正确；不重置重试或任务期限。
- 中英文信件、电报和日志在实际分辨率／UI 缩放下可读，纸面颜色与长文本无截断。
- 检查新的 error.log、game.log、debug.log 中 `ffpa_sc_cmf`、`je_group_ffpa_sc_cmf` 和相关 GUI／scope 错误。

若发布到 Workshop，还需将 CMF 加为 required item；此处没有执行发布、提交或推送。
