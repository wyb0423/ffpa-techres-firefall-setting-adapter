# 幸存者协定渐进会员收益

用户已确认本方案并授权实施；本文件取代旧设计中的固定会员收益数值。

| 有效合作月份 | 科技扩散 | 创新力产出 | 影响力 |
|---|---:|---:|---:|
| 0–23 | +5% | +2% | −5% |
| 24–71 | +10% | +4% | −10% |
| 72及以上 | +15% | +6% | −10% |

协调国另承担影响力−5%，不增加科研收益，不重置合作进度。
不增加固定创新点数或创新力上限。创新产出百分比与同类修正加算。
移除旧会员附带的迁移配额、恶名、军事投射威望及贷款利率效果。
专项教育、贸易、工程和援助池的现有规则保持不变。

## 实施

- 三个独立阶段 modifier 互斥，协调职责使用单独成本 modifier。
- 用 REPLACE 显式清空两个旧会员 modifier 的效果，并停止发放旧 ID；旧 ID 仅用于兼容识别和清理。
- 新增国家变量 ffpa_sc_cooperation_months，0起步、72封顶。
- 只由全局月度脉冲对有效合作会员各推进一次；刷新、提案、日志和身份切换不推进。
- 月度结算精度：每次有效月度脉冲累计1个月，24及72次结算后升级，不按入会日计算完整周年。
- 至少两个合资格会员且组织已成立才运作；暂停时保留月份，撤下会员及协调奖惩。
- 入会、退会刷新其余会员，使组织跨越两国门槛时及时更新效果。退会清空该国合作月份。
- 新迁移标记 ffpa_sc_membership_schema_2 独立于原 schema 1，使已迁移旧存档也能清理旧效果。无历史月份的现有会员从0开始，不回溯授予成熟阶段。
- 中英文同步更新入会、邀请、协调、退出和阶段说明，保留UTF-8 BOM。
