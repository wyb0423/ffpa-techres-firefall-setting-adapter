# 幸存者协定日志：文本与视觉设计

日期：2026-09-09。用户已批准“原生日志内分层 + 按任务类型展示”，并明确要求落实文本样式与排版。

## 1. 范围与实施

改造 `ffpa_sc_overview`、`ffpa_sc_task_journal`、关联按钮说明、教育／贸易／工程效果说明，以及 `ffpa_sc.1` 至 `.6` 六类事件正文。中英文同步。

顺序：核对原生排版和效果 → 分类改写本地化 → 调整只读展示分支与按钮顺序 → 富文本、分支及原有机制检查。

保留两个日志及既有 ID，不新增玩法日志、GUI、字体文件、计时器、经济效果或存档变量。展示脚本复用现有状态；按钮可见性、执行效果与 AI 不变。

## 2. 视觉语言

依据 myflavor `docs/flavor-design-toolkit.md` §7.9：中等偏丰富、语义明确、接近原版。先分清信息作用，再赋予样式。

| 用途 | 实际格式 | 视觉与使用规则 |
|---|---|---|
| 分区标题 | `#header …#!` | 原版白色粗体；独立一行，前留一个空行 |
| 关键行动 | `#b …#!` | 沿用正文色，仅强调短语 |
| 时间、票数、报价 | `#V …#!` | 原版白色粗体；注明月、年、周费等单位 |
| 收益／条件满足 | `#P …#!` | 原版绿色粗体，并保留文字或数值说明 |
| 成本／实际失败 | `#N …#!` | 原版红色粗体；成本增加虽为正数仍用负面色 |
| 待满足／暂停 | `#yellow …#!` | 原版浅黄色；表达需要关注，不伪装成已失败 |
| 辅助说明／未开放 | `#lore …#!` | 原版灰色；关键成本与必需条件不弱化 |

采用游戏现有字体与字号。中文不用模拟斜体，连续叙述保持默认样式，不整段加粗上色。段内使用 `\n`，分区使用 `\n\n`；不以空格对齐成表，不插入装饰分隔线或假按钮。

颜色来自安装游戏的 `game/gui/textformatting.gui`：白色约 RGB(240,242,224)、绿色约 RGB(99,171,84)、红色约 RGB(224,87,87)、浅黄约 RGB(255,247,168)、灰色约 RGB(153,145,140)。这些只是记录，未硬编码新的 GUI 色值。两个依赖没有覆盖同名文本格式文件。

投票赞成／反对、协调身份与表决结果使用中性强调；不以红绿判断政治立场。已有货币符号继续使用，不添加未经核实的图标。

## 3. 按原生容器排版

现场核对 `game/gui/journal_entry.gui`：`GetStatusDesc` 为大号、居中、深色背景；`GetReason` 为正文大小、左对齐、多行区域；按钮使用原生网格，名称有宽度限制。

因此顶部只放阶段、剩余时间和紧凑实时信息；条件、成本和规则放正文。没有通过更长的居中状态块模拟详细面板，也没有替换全局 GUI。原生按钮区仍在状态栏与正文之间，不能承诺新的折叠组或分页。

### 总览

- 顶部议会状态：等待会员／已提交／表决／休会／可提案；表决时提供议题、期限、票数、资格总数与本国立场。
- 正文：简短背景 → 长期协议 → 限期工程 → 五类援助 → 本国每周援助收支。
- 援助执行中的提供国数量与全组织周资金池保留，使用次级行；本国报名、接受服务、提供服务分别标识。
- 按钮顺序：投票 → 提案 → 协议参加／退出与工程 → 援助报名。顺序不是新增按钮分组控件。

### 活动任务

| 类型 | 顶部状态 | 左对齐正文 |
|---|---|---|
| 教育准备 | 阶段、剩余月份 | 背景；童工保护与学校制度分别显示满足情况；下一步；准备期限制 |
| 贸易准备 | 阶段、剩余月份 | 背景；对外贸易法律条件；下一步；准备期限制 |
| 公共工程 | 阶段、剩余工期 | 施工协作背景；建设收益；维护成本；期限与限制 |
| 援助报名 | 类型、报名期限、本国已报名 | 全额服务基准；当前未收费；锁定报价；执行期限与退出条件 |
| 援助执行 | 类型、剩余月份、接受服务、全组织供给摘要 | 全额服务基准；本国实际周费；供给缩放／已精简投入；期限与退出条件 |

正在立法、组织暂停和 AI 行政余量不足只改变“下一步”提示，不再盖掉期限与条件清单。提示优先级：组织未运行 → 已有立法 → AI 行政余量不足 → 按教育／贸易给出行动。

实际周费仅在服务费修正和已应用费用变量同时存在时读取；否则明确显示当前未收费。全额报价不冒充当前支出。缺少可识别任务时显示待更新，不回退成贸易任务。

### 按钮与效果说明

协议／工程按“收益 → 维护成本 → 参加条件、期限与限制”排列，每个数值独立成行。提案／投票按程序与通过条件排列；退出／中止按停止事项与保留限制排列。

援助报名说明先给全额服务收益，再列全额周报价、当前供给预计报价与报名／执行规则。报价使用中性数值；已经生效的本国服务支出用成本色。

### 事件

保留现有独立 flavor 叙事字段，不将其改成规则清单。

| 事件 | 正文层次 |
|---|---|
| 入会邀请 `.1` | 合作邀请 → 会员成长收益与投入 → 生效条件 |
| 开议通知 `.2` | 时间窗口 → 本国行动 → 表决与参加的区别 |
| 表决结算 `.3` | 结果 → 休会与报名安排 → 查看实际开放状态 |
| 准备失败 `.4` | 明确失败 → 重试时间 → 保留成果 |
| 旧档适配 `.5` | 已完成适配 → 需要重新选择 → 保留现状 |
| 年度复核 `.6` | 复核背景 → 维持／精简／退出的差异 → 保留期限 |
