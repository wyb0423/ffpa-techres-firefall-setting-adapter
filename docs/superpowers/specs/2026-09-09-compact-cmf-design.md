# 幸存者协定 CMF 接入

2026-09-09：用户批准推荐版，并授权实施。基线为本地 CMF 1.65.0 / Victoria 3 1.13.*；保留工作树已有援助、事件和日志修改。

## 范围

- 声明 CMF 硬依赖，加载于 CMF、Tech & Res、Firefall 及共享法律覆盖之后。
- 使用 CMF 国际组织侧栏，新增唯一的公共 contextless 总览，显示成员、协调国及议会信息。国家总览和任务日志保留原 ID 与按钮。
- 议会显示实时票数、当前通过所需赞成票、时间与本国立场。投票和三个月／九个月时钟继续由既有脚本驱动。
- 任务进度显示当前阶段已用时间，准备期 60 月、工程／援助执行期 36 月、援助报名期 1 月。进度达到末端不代表满足改革条件或额外奖励。
- 邀请采用 CMF 简洁信件；开议、结算采用窄版电报，保留默认字体，避免中文手写／打字机字体与纸面浅色文字。其余长事件保留原样。

## 实现与生命周期

公共页只读，成员仍由 ffpa_sc_membership 及资格条件定义，协调国从成员中的现有标记展示，不建立主席或总部制度。独立 contextless 分组只注册一次；初始化从开局和现有全局月脉冲进入，覆盖旧档。组织创建后长期存在，少于两个会员显示等待；退会不关闭框架的共用侧栏。

进度使用 CMF GUI 挂载点和 com_progressbar_base，直接绑定只读 script values。该底层组件允许覆写 value、纹理和 tooltip，无须创建 styled scripted bar 的角色容器或缓存，也无第二套时钟；任务退出、阶段切换和读档由当前状态直接决定显示。

## 第二批：2026-09-09 用户批准前三项

1. 公共页按赞成、反对、弃权／未表态、无资格分组显示本轮会员名单，并标注提案国。分类用实际资格和选票，仍不区分弃权与未表态。
2. 公共页提供五类援助切换，分别显示提供／报名或接受国家、供给比例与原因、全池每周资金、本国实际收支。报名不显示已经收费；没有活动资金池时不读取残留收费数据。
3. 国家总览用议会、长期协议、工程与援助三个 GUI 分页展示原 scripted buttons，仍执行原按钮对象；公共页与国家总览双向跳转，只在目标有效且活动时启用。GUI 分页选择不承载游戏状态。

引用只用于导航。新日志 immediate 设置引用；已有日志在初始化／月脉冲补齐，失效国家引用清理。无需新增日志、改变 AI 或增加结算／履约时钟。更早的长文本保留为辅助说明。第二批不实施历史记录、终止原因或会员成长展示。
