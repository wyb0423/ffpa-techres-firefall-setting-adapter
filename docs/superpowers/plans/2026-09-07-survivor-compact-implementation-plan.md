沿用当前 Mod ID `com.wyb.ffpa-techres-firefall-setting-adapter`，硬依赖仍为 `tech.res` 和 `alter_time_2050_fire_falls`。不拆新包，不改八项科技的结构与已批准效果。版本号与 metadata 描述在机制实际可交付时更新，不能现在把 0.2.0 宣传成已包含新机制。

保留单一组织、普通会员与主要协调国、议会、教育和贸易协议、单个三年工程项目。取消旧调停、领土裁判、强制改法和组织章程对未签约国家的额外压力；不修改原生战争、文化定居、和平统一和独立的核条约规则。

最新玩法与数值以研究文档第 7.8–7.13 节为依据。此前“独立机制包”和已取消的调停计划不再执行。

## 3. 状态与周期

新持久状态使用独立前缀，不复用旧 `ztr_un_hr_*` 数值表达新协议。保留必要的旧身份兼容出口，但不能为了兼容而返回错误会员资格或触发旧强制执行。

- 全局：迁移版本、组织存在、三个协议是否开放、当前议题及表决资格、表决截止与冷却、席位复核时点。
- 国家：会员／协调意愿、投票选择、协议参加与达标状态、唯一活动任务、原准备截止、重试冷却、工程开始与可再启动时间。
- modifier 是状态计算后的效果，不同时作为另一套相互矛盾的参加记录。加入、退出、月度检查、读档迁移都通过同一状态更新入口。
- 表决全局统一计时，固定三个月；结算后九个月冷却。国家日志只显示或提交选择，不各自推进全局倒计时。优先使用已验证的日期／到期机制；若必须用月度计数，必须有全局唯一推进和启动月边界测试。
- 开议完成议题、提案者和资格初始化后通知并执行首次 AI 判断；月度重评，结算前最后重算。票数、资格分母和三分之一最低支持门槛来自同一集合。
- 加入只创建总览。未选择协议无期限，已达标自选参加无准备日志，最多一个主动准备／项目日志。
- 一次迁移有版本标记，重复读档不再清状态。退会和暂停只清理界面与当前效果，不删除防止重刷期限的历史日期。

## 4. 实施批次

### 第一批：身份、兼容与迁移

1. 保存上游目标定义与引用清单，确定新游戏初始化及旧档迁移入口。
2. 实现成立、主动入会／邀请、普通退出、协调职责自选、成员不足两国的暂停。
3. 按显式清单迁移旧身份与机构，作废旧表决和自动任务；处理已排程旧事件，移除旧修正，不回滚本国法律、科技或建筑。
4. 接入新总览，确认晚入会不批量启动协议；兼容核条约会员识别。

完成标准：新档和旧档都只有一套组织状态；重复迁移无副作用，入退会不强制改法、不刷奖励，单成员没有合作收益。

### 第二批：议会与 AI 投票

1. 实现一国一票、普通议案无否决、赞成多于反对且至少三分之一会员／至少两国的通过规则。
2. 设置三个月投票、九个月冷却，共享玩家和 AI 入口；新会员下轮投票，退会清票并重算。
3. AI 从未开放的三项中选择议案。表决评价开放渠道，参加评价本国实际负担，两者分开。
4. 从调试记录区分未提案、弃权、反对、票数不足和调度未触发，不以统一提高赞成概率替代修正流程。

完成标准：改变会员数量不改变投票实际时长；有需求且关系允许的 AI 能提出并通过合作，分歧局面仍能失败；玩家与 AI 冷却一致。

### 第三批：教育、贸易与工程

1. 教育：正常立法、至少一级学校、准备／达标／倒退／失败／退出；玩家与 AI 共用有效行动入口，不强行取消其他立法或赠送学校等级。
2. 贸易：核对最终贸易法律及变体，已达标自选参加；未达标沿用同一准备流程，保持最大关税与实际收入语义准确。
3. 工程：主动三年项目、五年启动间隔，与准备任务共用活动名额；中止不退款、不刷新日期。
4. 全部按已确认数值赋予效果：工程官僚产出 -5%，与贸易合计 -10%；AI 按叠加负担判断，不按单项分别通过后全部开启。
5. 确保旧机构自动赋予效果、旧日志和按钮不绕过新参加条件；清理旧法律和独立倾向外溢。

完成标准：AI 不仅投票，还能参加、启动正常改革和投资；失败可解释。三个合作的收益与成本同步启停，无旧值残留、重复叠加或额外自动日志。

### 第四批：本地化、组合验证与交付

1. 英文和简体中文键成对、保留 BOM，术语与数值一致；避免把受教育机会写成即时识字率、把荒废恢复写成辐射清理。
2. 校验 metadata、脚本结构、引用、重复顶层覆盖和最终加载关系；运行 `git diff --check`。
3. 留一个最小可运行检查入口，验证数值清单、表决边界、参加／退出状态与日期保留；优先让检查读取实际配置，避免测试只复制实现。
4. 实机分别覆盖两个前置，以及额外启用 Core Balance／文化定居的组合；检查新档、旧档和 error/game/debug 日志。
5. 机制完成后更新版本与 README 的已实现说明，写出实测范围及仍存在的限制。未运行游戏时只报告静态检查通过，不标记实机验收完成。

## 5. 最小实机样本

| 样本 | 重点 |
|---|---|
| 2、3、10 个会员 | 投票时长一致；全弃权、平票、一票赞成不能误通过 |
| 弱国、贸易国、科研领先国 | 参加的收益／成本差异，避免强制全开或普遍无用 |
| AI 初始不达标但有改革条件 | 提案、表态、参加、立法、学校投资、最终达标全过程 |
| 已有立法／无科技／官僚不足／财政困难 | 合理等待、不抢占立法、有限失败、无免费达标 |
| 三项已开放后晚入会 | 一个总览，无自动准备倒计时；最多一个主动任务 |
| 退会重入、倒退、途中读档 | 效果清理、原截止保留、不能刷五年期限或工程冷却 |
| 旧投票／旧机构／旧核条约 | 无旧决议执行和重复奖励，条约与锁定期继续有效 |
| 文化定居及统一战争各模式 | 仅解除组织附加限制，不改变原本定居、恶名和开战规则 |
