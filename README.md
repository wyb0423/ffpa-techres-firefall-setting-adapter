# FFPA — Tech & Res Firefall Setting Adapter

为 `[1.13] Tech & Res` 与 `2050: The Fire Falls` 提供轻量世界观适配。当前开发版包含十四项社会科技适配，并将联合国机制改造为“幸存者协定”。不改科技树结构、开局科技档位或解锁关系。

机制脚本已写入当前项目，静态与局部状态检查通过；尚未完成游戏内验收。安装包沿用原 Mod ID，不需要第二个机制 Mod。

当前决策见[联合国改造设计](docs/2026-09-07-un-system-research-and-options.md)，施工顺序见[实施计划](docs/superpowers/plans/2026-09-07-survivor-compact-implementation-plan.md)。
后续资金池、AI 与年度执行方向以[玩法扩展记录](docs/2026-09-08-un-gameplay-inventory-and-expansion-options.md)的最新章节为准。

人口恢复批次增加六项科技效果：五项出生率各 +5%，劳动力比例合计净增 10 个百分点，死亡率额外降低 4%。其他科技收益保留；具体改前／改后数值见[人口恢复设计](docs/superpowers/specs/2026-09-09-population-recovery-design.md)。游戏内人口和就业表现由另一台机器验收。

## 必要前置与加载顺序

- `[1.13] Community Mod Framework`，Workshop ID `3385002128`（本次核对 1.65.0）；
- `[1.13] Tech & Res`，Workshop ID `3472248460`；
- `2050: The Fire Falls`，Workshop ID `3768192009`。

推荐顺序：

```text
[1.13] Community Mod Framework
→ [1.13] Tech & Res
→ 2050: The Fire Falls
→ FFPA — Tech & Res Firefall Setting Adapter
```

本适配包必须最后加载；后加载且再次定义相同科技 ID 的 Mod 会覆盖它。

CMF 接入增加国际组织侧栏中的“幸存者协定 · 议会”，用于查看会员、协调国和表决状态。投票、提案及履约仍在本国原有日志中操作。投票条显示当前门槛；任务条显示阶段已用时间，不代表改革成功。邀请采用简洁信件，开议与结算采用默认字体的窄版电报。详见 [CMF 接入设计](docs/superpowers/specs/2026-09-09-compact-cmf-design.md)。

既有存档会在初始化或下一次全局月脉冲补建一次公共组织页；不重置合作年限、投票、援助或原定期限。发布 Workshop 时还需在发布页面设置 CMF 为 required item；本地元数据不能代替发布页面设置。

公共页还提供投票分类名单、提案国标记与五类援助明细。报名期的供给为预计值，执行期显示结算供给及实际周收支。本国总览按“议会／长期协议／工程与援助”分组原按钮，并与公共页双向跳转；弃权和未表态继续合并展示。检查与实机验收清单见 [CMF 验证记录](docs/2026-09-09-compact-cmf-validation.md)。

如同时启用文化定居等会覆盖共享法律的可选 Mod，本适配包仍放在它们之后，并核对最终法律定义；不新增硬依赖，不复制其定居逻辑。

## 首版改动

- `transnational_activism` → “跨境互助网络”：弱化知识分子单一加成，加入工会互助与较温和的外交约束。
- `global_stock_market` → “跨区结算网络”：改为铸币、政府分红与贸易容量加成。
- `globalization` → “战后再联通”：保留公司数量，并改为贸易容量和市场接入加成。
- `social_media` → “网状公共空间”：降低影响力加成，同时削弱政府权威。
- `app_economy` → “分布式服务平台”：保留最大公司数量 `+1`，并增加电商物流与办公楼吞吐量。

没有使用 `replace_path`。既有存档继续沿用原科技 ID；载入后应按当前最终定义重新计算科技修正。

## 兼容与验收

Tech & Res 或 Firefall 更新后，需要重新比较这八个完整科技对象并吸收上游新增字段。建议在新游戏与已研究相关科技的旧存档中检查科技名称、说明、tooltip 与实际修正，并在用户日志目录的 `error.log`、`game.log`、`debug.log` 中搜索本适配包相关解析错误。

| 非殖民化 → 继承政权承认 | 威望 +25%；对未受认可国家恶名 +20% | 威望 +10%；对未受认可国家恶名 +10% |

三项原有布尔 modifier 均保留；0.3.0 另通过机制脚本接管联合国及其非殖民化附加规则。研究科技不代表组织已经成立。一般恶名加成不会判断战争正当性。

中等科技档案开局包含第一项，先进档案包含三项。0.3.0 移除了上游因国际组织科技／会员身份而额外压低领土、殖民扩张 AI 权重的规则；其余策略条件保留。和平统一外交行动、核条约、生产方式及开局科技档案均未修改。

## 0.3.0：幸存者协定

- **成立与加入**：独立、非分裂／革命、非分散国家可参加；拥有国际组织科技的合格国家可发起。至少两个实际会员启用合作。晚入会只显示总览，专项合作自选。
- **协调席位**：最多三国，自愿报名、按威望排序，每年复核；空缺递补。只有提案权，每国仍一票，无否决权。可辞去职责而不退会。
- **议会**：提案进入下个月度议程，开议后完整表决三个月，结算后冷却九个月。赞成多于反对，且不少于有效投票资格国家的三分之一、至少两国才能通过；弃权计入资格分母。中途加入下轮投票，退出清除本轮资格。
- **教育与贸易**：达标后可直接参加；不达标可自选五年准备期，沿用正常立法、学校投资。准备期没有专项效果和额外收费；到期失败后三年重试。达标后制度倒退会同步暂停该项收益和成本。
- **三年工程**：需有在建建筑；持续三年，两次启动至少间隔五年。与未完成的协议准备共用一个活动任务名额，已达标持续协议不占名额。
- **援助资金池**：教育普及、人才培养和生产／社会／军事科研共五池。表决通过后报名一个月，有供援国和受援国才启动三年执行。受援方支付服务费，按威望向提供国分账；提供国承担对应服务代价。与工程共用活动名额及五年启动间隔。
- **年度执行选择**：援助运行满一年，可维持、精简、采用替代方向或退出。科研可转为知识推广，人才可转为师资培养，教育可扩大覆盖。替代方向替换原收益、费用不变，每轮只能选择一次；期限和冷却不重置。供援国数量变化时，费用与收益同步缩放。
- **退出与旧档**：退出清除当前组织效果，保留原期限和重试限制。旧会员迁移为普通会员，旧机构映射为已开放选项；旧议案、强制执行与自动任务停用。旧法律、建筑、科技、领土和核条约不回滚。

| 合作 | 收益 | 对应成本 |
|---|---|---|
| 会员：有效合作 0–23 个月 | 科技扩散 +5%、创新力产出 +2% | 影响力 −5% |
| 会员：有效合作 24–71 个月 | 科技扩散 +10%、创新力产出 +4% | 影响力 −10% |
| 会员：有效合作 72 个月起 | 科技扩散 +15%、创新力产出 +6% | 影响力 −10% |
| 主要协调国 | 沿用本国会员阶段收益 | 额外影响力 −5% |
| 教育 | 科技扩散 +25%、受教育机会 +5 个百分点、资质 +25% | 学校制度官僚成本 +25%、政府工资 +10% |
| 贸易 | 进口／出口优势各 +25%、贸易容量 +20% | 最大进口／出口关税各 −10 个百分点、官僚产出 −5% |
| 工程 | 地区建造力效率 +20%、荒废度恢复 +25% | 建造商品花费 +10%、官僚产出 −5% |

贸易修正适用于本国对外贸易，无法仅限定成员之间的交易。受教育机会不会即时转为识字率，荒废度恢复也不清除辐射。工程和贸易同时生效时官僚产出合计 −10%，教育另有学校成本。

会员阶段只在组织正常运作时累计，退会重置；协调身份变化不重置进度。援助资金池的费率和教育增长仍是试用参数；提供国实际收入仅 +1 的反馈尚未结案，诊断方法见[资金池排查记录](docs/2026-09-09-aid-pool-modifier-investigation.md)。

AI 区分开放合作渠道与实际参加：表决考虑需求和有限的外交关系影响；参约检查改革可行性、官僚、债务与战争状态。正常立法入口不取消其他立法、不保证通过；学校投资通过原生 AI 优先级引导。财政判断使用当前账面余量，后续实际表现仍需游戏观察。

旧档首次月度检查执行一次迁移；无法可靠读取的旧四年议会冷却清除一次。教育／工程期限由游戏日期变量管理，日志剩余月份是按月更新的近似显示。成员不足两国时合作暂停，工程中止且原启动冷却保留。
